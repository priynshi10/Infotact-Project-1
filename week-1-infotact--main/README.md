# AETHERHOUND
## Air-Gapped RF & Acoustic Covert Channel Detector
**Development Phase:** WEEK 1 – Real-Time Hardware Acquisition, Signal Processing & Covert Pattern Detection  
**Target Environment:** Linux, Raspberry Pi 4 / Raspberry Pi 5, x86_64 Debian/Ubuntu  

---

## 1. Project Introduction

**AetherHound** is a signals intelligence (SIGINT) and hardware security platform engineered to detect unauthorized covert data exfiltration channels from air-gapped computers. 

Air-gapped systems—isolated from local networks and the Internet—can still leak sensitive data via physical side-channels:
1. **Electromagnetic RF Leakage:** Spurious radio-frequency emissions generated by memory buses, display cables, or switching power supplies manipulated by malware.
2. **Acoustic Covert Channels:** Malware manipulating system fan speeds (PWM signals) or internal speakers to transmit data through ultrasonic or high-frequency acoustic vibrations across an air gap.

AetherHound captures, processes, and detects these covert channels **concurrently and in real time** while acquisition is running.

---

## 2. Week 1 Objectives

Week 1 delivers a functional real-time hardware monitoring and detection prototype composed of two primary modules:

- **Module 1: Real-Time Hardware Acquisition & Monitoring**
  - Continuous IQ sample capture via **RTL-SDR** (DVB-T dongles).
  - Continuous audio sample capture via **PyAudio** non-blocking streams.
  - Windowed Fast Fourier Transform (FFT), Power Spectral Density (dBFS), noise floor estimation (Median Absolute Deviation), and spectral peak tracking.
  - Statistical RF anomaly detection and acoustic burst detection.

- **Module 2: Benign CPU Fan Morse-Code Simulator & Real-Time Pattern Recognition**
  - Benign software simulation of CPU fan RPM trajectories encoding International Morse Code ("SOS").
  - Synthesis of aerodynamic fan acoustic waveforms with Blade Pass Frequency (BPF) harmonics.
  - Real-time streaming acoustic detector that extracts envelopes, classifies dot/dash pulse durations via an adaptive Schmitt trigger, and matches the target "SOS" pattern while audio is arriving.

## 4. RTL-SDR Driver & Library Installation

### On Linux / Raspberry Pi:
```bash
sudo apt-get update
sudo apt-get install -y rtl-sdr librtlsdr-dev libusb-1.0-0-dev

# Prevent Linux kernel DVB-T TV tuner driver from claiming RTL-SDR:
echo 'blacklist dvb_usb_rtl28xxu' | sudo tee /etc/modprobe.d/nortlsdr.conf
sudo udevadm control --reload-rules && sudo udevadm trigger
```

### On Windows:
1. Plug in RTL-SDR dongle.
2. Run **Zadig** (`zadig.exe`), select `Options -> List All Devices`.
3. Select `Bulk-In, Interface (Interface 0)`.
4. Install the **WinUSB** driver.

## 12. Real-Time Detection Explanation

### Statistical RF Detection (`detection/rf_detector.py`)
- Calculates calibrated power spectrum in dBFS for every 2,048-bin FFT window.
- Estimates the local noise floor using normalized **Median Absolute Deviation (MAD)**:
  $$\text{NoiseFloor} = \text{median}(P_{\text{dB}})$$
  $$\sigma_{\text{noise}} = 1.4826 \times \text{median}(|P_{\text{dB}} - \text{NoiseFloor}|)$$
- Identifies spectral peaks exceeding the threshold ($\ge 4.5 \sigma$).
- Applies a **persistence filter**: peaks must persist across $\ge 3$ consecutive windows to prevent transient false alarms.
- Uses hysteresis to prevent alert flickering.

### Acoustic Morse Detection (`detection/morse_detector.py`)
- Extracts the envelope using a continuous streaming single-pole envelope follower.
- Tracks dynamic range using rolling percentiles ($P_{15}$ and $P_{85}$).
- Implements an adaptive **Schmitt trigger** with hysteresis ($th_{\text{high}} = P_{15} + 0.54 \Delta, th_{\text{low}} = P_{15} + 0.36 \Delta$) to cleanly segment pulses without false edge flutter.
- Classifies intervals into dots ($\sim 0.20$s) and dashes ($\sim 0.60$s).
- Evaluates the rolling 9-symbol sequence for `... --- ...` ("SOS").
- Calculates a mathematical match score:
  $$\text{MatchScore} = 0.70 \times (1.0 - \text{MeanTimingError}) + 0.30 \times \text{Fidelity}$$

## 17. Troubleshooting

- **`usb_open error -3` on RTL-SDR:**
  The kernel DVB-T driver is blocking access. Ensure `blacklist dvb_usb_rtl28xxu` is added to `/etc/modprobe.d/` and run `sudo rmmod dvb_usb_rtl28xxu`.
- **`ALSA lib pcm.c: Unknown PCM` messages:**
  Harmless informational messages emitted by ALSA in headless container environments when no physical sound card is present. The software mode and synthetic generators work independently.
- **Microphone dropped chunks:**
  Increase chunk size via `export AETHERHOUND_AUDIO_CHUNK_SIZE=4096` or reduce sample rate to 22,050 Hz on slower embedded processors.

## 18. Known Hardware Limitations

1. **RTL-SDR Bandwidth:** RTL-SDR is bandwidth-limited to $\le 2.4$ MHz stable bandwidth. Wideband RF exfiltration across multiple GHz requires frequency stepping.
2. **Receive-Only Operation:** AetherHound is an authorized surveillance and defense sensor; it does not and cannot transmit RF signals.
3. **Microphone Frequency Cutoff:** Standard electret USB microphones typically roll off steeply above 20 kHz. Ultrasonic covert channels ($>22$ kHz) require dedicated high-sample-rate ultrasonic acoustic transducers (e.g. 96 kHz or 192 kHz).
